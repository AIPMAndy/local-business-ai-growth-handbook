# 本地生意 AI 获客落地 SOP

## 一、一次只解决一个核心问题

每周选择一个阶段：发现 → 信任 → 咨询 → 到店 → 成交 → 复购。按以下诊断顺序：

- 找不到门店：修地图信息、分类、营业时间；保留顾客端搜索截图。
- 有播放没咨询：核查内容是否回答购买前问题、主页联系入口是否清楚、服务范围是否可判断。
- 有咨询没预约：核查话术、地区匹配、服务时段、价格透明度；记录未预约原因。
- 有预约没到店：核查确认提醒、位置导航、到店规则；不要群发骚扰。
- 到店不成交：核查服务解释、真实供给、价格条件、技术信任；尊重顾客选择。
- 成交不复购：先修交付体验与售后，合法取得触达授权后再设计服务提醒。

## 二、合格咨询的统一定义

必须同时满足：**服务范围可交付、地理位置匹配、用户表达了明确的实际需求。** 只说“多少钱”但没有场景的线索，先放“待补信息”而不是擅自判定为合格。咨询来源不明确保留“未知”。

## 三、每天的操作时间盒

经营人忙时只安排：10分钟回答顾客/整理问题、15分钟拍一个真实素材、10分钟复盘线索。这个时间分配是**建议**，不是对所有行业有效的最优解。先能连续做到，再考虑提高频率。

## 四、15秒首问模板

“你遇到的具体情况是什么？大概在什么区域？方便到店还是希望先了解？我先看是不是我们能处理的，再跟你说下一步和收费方式。”

## 五、三问采访模板

1. “遇到这个问题时，普通人通常先误判什么？”
2. “你会看哪两个证据，怎么排除其他原因？”
3. “普通人遇到类似情况，先自己检查什么？什么时候必须交给专业人员？”

## 六、经营数学

设合格咨询数 L、到店数 V、订单数 O、每单实收 R、每单变动成本 C、每条咨询获客成本 CPL、额外营销费 F、新增工时 H、小时成本 W：

```
咨询→到店率 = V / L（L=0 时无定义）
到店→成交率 = O / V（V=0 时无定义）
每单贡献毛利 = R - C
本期新增净贡献 = O × (R - C) - L × CPL - F - H × W
每单新增营销成本 = (L × CPL + F + H × W) / O（O=0 时无定义）
```

对比前后两期时，必须保证统计口径相同，备注天气、节假日、活动、产能和价格变化。样本量小则只能说“观察到了变化”，不能直接宣称内容导致增长。

## 七、数据字段必须能审计

一个真实合格线索至少需要日期、匿名ID、来源、需求、是否匹配、下一步动作；实际成交需要真实实收与变动成本的可追溯凭证。不要把客户姓名、个人手机号、车牌直接存进公开CSV。归因允许“未知”。
