# 官方资料与适用边界（检索于 2026-11-10）

1. **高德地图商家开放平台** https://bgc.amap.com/：官方商家入驻与地点标注，基础地图入驻与营销服务不是同一笔费用。具体界面实时核对。
2. **高德地点标注中心** https://g.amap.com/center：官方地点新增和认领。所需身份与门店证明材料须从当前官方页面核查，仅提交至官方后台。
3. **百度地图商户中心** https://didian.baidu.com/：商家地点新增/管理，营业时间、电话、门店展示与顾客反馈。
4. **大众点评商家入驻** https://e.dianping.com/claimcpc/page/index?source=dp：平台可要求营业执照、门店照片等；部分商业合作/团购服务按页面显示和合同实际收费。
5. **大众点评商户认证** https://www.dianping.com/business/vshop/：商户认证、商家信息及评价管理介绍。
6. **抖音来客官方App说明** https://apps.apple.com/cn/app/id1603172928：官方出品的生活服务商家经营平台，功能包括门店管理、团购与营销；具体类目资格需要在最新官方入驻流程确认。
7. **国家市场监管总局《互联网广告管理办法》** https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_d93a579afd45413e8576e4623fab348f.html：广告可识别、真实性、禁止欺骗误导以及推广跳转等相关规定。

## 主张证据表

| 主张 | 证据等级 | 边界 |
|---|---|---|
| 地图商家可申请标注/认领 | 官方直接可核查 | 申请不意味着立即通过；规则可能更新 |
| 点评商家可办理入驻、认证等 | 官方直接可核查 | 是否收费与费用按行业/合同为准 |
| 抖音来客提供门店经营功能 | 官方应用介绍 | 不代表所有行业都能上架相同团购 |
| AI可以辅助脚本/问答/归纳 | 方法建议 | 不保证输出正确，也不自动发布 |
| 30天可能建立最小获客链路 | 作者提出的行动计划 | **非官方承诺，更非30天赚钱保证** |
| 某个门店用这套方法实现获客增长 | **没有公开证据** | 不宣称，不填写虚假成果 |

未来更新时需要核实页面是否仍然有效、类目政策变化、实际成本与结果口径。
